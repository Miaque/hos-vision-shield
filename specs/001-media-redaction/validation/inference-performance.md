# 同效果CPU推理优化（2026-10-19）

以`24c8201`中的quality效果作为基线，不调整四个模型、阈值、检测分辨率、重叠分块、扩框、局部确认规则或视频200毫秒历史框补偿。文件视频继续逐帧处理，不采用抽帧、相似帧近似或跟踪框替代检测。测试硬件为本机Intel i5-10400，CPU权重和素材保持原哈希；不涉及CUDA或新依赖。

## 瓶颈与改动

逐模型计时确认EgoBlur是主要开销。远处车牌图的约7.78秒中，全图EgoBlur双模型约7.29秒；人群图约19.78秒中，六次EgoBlur局部复核约11.14秒。局部只消费一种候选类别，但原先两份独立模型都会执行。

1. 两种候选提供器增加内部可选`kind`参数。全图不传参数，仍执行两类模型并沿用原校验；局部传入待确认类别，只跳过不会被消费的另一类模型。目标模型的输入、预处理、NMS、得分校验和异常传播不变。初始模型加载仍要求四个权重全部可用，不引入缺失模型回退。
2. EgoBlur每个媒体子进程从2个Torch计算线程调整为4个，OpenCV仍为2个；不增加任务池worker或每帧并发。模型推理保留`inference_mode`与现有TorchScript优化开关。

## 分项试验

原方案、仅按类复核、再加4线程以相同输入交错运行两轮。以下为两次耗时的中位数，不含模型初始化；所有轮次的完整RGB遮挡像素哈希一致。

| 方案 | 人群图 image-07 | video-04第24帧 |
|---|---:|---:|
| 原方案，2线程、双类复核 | 21.45秒 | 14.99秒 |
| 仅按类复核，2线程 | 14.29秒 | 14.58秒 |
| 按类复核，4线程 | 11.76秒 | 11.34秒 |

另对固定视频帧进行2、1、4、6、2、4、6、1线程交错试验，仅运行原EgoBlur全图双类模型；各两次中位耗时分别约12.39、19.95、8.75、8.30秒，遮挡像素一致。保留4线程以取得明显收益并减少多媒体进程竞争；6线程相对收益较小，不作为默认值；1线程明显更慢，放弃。

试验记录在本机忽略目录`data/validation/performance-20261019/`：`baseline-profile.json`、`thread-probe.json`、`stages.json`与`stage-summary.json`。这些数据均来自实际权重推理；计时过程未与另一项模型负载并行运行。阶段试验与整批性能分别报告，不把局部推理时间当作API、队列或完整任务耗时。

## 验证边界

完整批次重新调用生产图片、视频处理器，计时包含解码、检测、遮挡及编码，不含模型初始化与API/队列。优化前复用同机轮胎修复后的固定记录，优化后新运行；分项试验另以交错两轮测量，不能将单次批次数据当成多轮平均。

| 范围 | 优化前 | 优化后 | 耗时减少 | 输出一致性 |
|---|---:|---:|---:|---|
| 全部16张原图 | 155.3007秒 | 105.9465秒 | 31.78% | 16份JPEG逐字节一致 |
| video-04约一秒、26帧连续片段 | 386.7448秒 | 260.2328秒 | 32.71% | MP4逐字节一致 |

图片吞吐约为原来的1.47倍，视频约1.49倍。视频另逐帧检查编码前完整RGB遮挡像素与编码后解码画面，全部一致，帧数26、源时间戳最大误差0；该原片没有音轨，AAC机制由视频回归测试覆盖。五个轮胎误检源帧的保留区及同帧车牌、人群图的三处真实面部内区继续通过，共核对19个固定区域。21个原始媒体文件SHA-256未变，四个权重哈希仍与基线一致，详见`verification.json`。

人群图的整图处理19.8973 → 9.7056秒；它和上方交错试验的输入相同，进程模型驻留及计时边界不同，分别保留原始数据，不将两组数据混用。

真实类别一致性回归使用同一幅授权人群图的近处人脸裁剪：两种候选提供器的单类推理结果须与双类推理中的相应类别在框、得分和顺序上完全相同，并要求样本实际检出人脸。单元回归另验证局部不得执行无关类别、类别传递和原有非法输出/异常失败边界。媒体输入与安全限制没有调整。

另外四段原定一秒片段各取前三个连续帧，分别以优化前代码快照和优化后代码实际推理，按相同源时钟进入FrameRedactor，12帧完整RGB遮挡像素哈希一致。三帧检测加遮挡耗时分别为video-01的23.218 → 16.425秒、video-02的22.666 → 14.987秒、video-03的38.650 → 26.400秒、video-05的41.491 → 27.950秒；这些是三帧探测结果，不代表另外四段视频全帧或全长计时，详见`other-clips.json`。

最终执行`uv run python -m pytest tests/unit tests/integration/test_video_pipeline.py tests/integration/test_quality_model_probe.py::test_single_class_confirmation_matches_the_same_real_models_running_both_classes -q`，98项通过、2条上游Torch警告，耗时12.19秒；日志`tests.log`。这包含97项单元及媒体机制测试和1项真实权重类别一致性测试。全部16张图片与38张视频源帧的实际推理、像素和文件检查另有记录，不将素材数相加为pytest测试数。没有删减旧质量断言或把缺失素材改成跳过。

4线程是本机CPU校准值，换到核数更少、并发更高或不同推理库的环境需要重新测量。即使本轮素材完全一致，也不能由此给出全场景召回率或CPU实时播放承诺。历史RTSP绿牌截图仍缺失，不把完整历史质量套件标为通过。
