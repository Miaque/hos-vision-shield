# 车牌可辨识性与额外计算边界（用户更新于 2026-10-25）

本文件记录用户最新质量与工作量要求，后续路线 A 车牌优化按此执行。
现有服务器还没有启用新的可辨识性判定或跳过逻辑，不能把本文当作实现或验收通过。

## 要求

清晰、可辨识的车牌必须遮挡。极小或严重模糊、确实不可辨识的车牌，不再为找回和反复确认
投入额外模型计算。判断依据是原始画面的车牌尺寸和清晰度，不能用检测置信度低替代不可辨识。
视频中目标靠近、尺寸增大或画面变清晰后，要及时恢复正常检测、确认与遮挡。

执行边界：

- 只对明确不可辨识的车牌跳过额外恢复；清晰或不确定的候选保留现有确认保护。
- 检测置信度继续用于现有车牌候选确认，不能作为可辨识性标签；清晰低分候选不得直接排除。
- 可辨识性也不证明候选一定是车牌，不能用清晰度自动放行假阳性或替代类型确认。
- 已经直接检出的目标无需额外恢复就能遮挡，不为取消这些遮罩额外增加工作。
- 持续保留新目标发现与周期检测；不把位置或轨迹加入永久忽略列表。
- 根据当前原始画面重新判断，不能沿用之前的小尺寸、模糊或负判定阻止后来清晰的目标。
- 保持现有人脸规则、两路常驻流和至少两个 GPU 文件实际并发、媒体完整性及失败关闭要求。

## 已定位的调用点

1. `detection/quality.py::Detector.detect_regions` → `_confirmed`：弱车牌候选的跨模型局部确认。
   先保留已有全图结果可直接确认的路径，再决定是否需要进行额外放大推理。
2. `redaction.py::FrameRedactor._proposal_recheck`：未覆盖的候选触发额外全量复查。
   当前只有短边 12 像素的粗过滤，不等于原图可读性规则，不能据此认定满足新要求。
3. `FrameRedactor.regions` 的 flow 失败与 `_recheck`：旧车牌轨迹失配、陈旧时的找回与再次确认。
   对明确不可辨识目标不重复启动昂贵找回，同时保留后续正常发现与状态恢复。

`_confirmed` 与 `_recheck` 都会截取周边区域并放大到 320 像素；可辨识性必须在该放大之前
从原始目标判断，不能用补偿后尺寸或放大后清晰度作依据。
局部复查还会将放大视图传回 quality 检测，必须避免在嵌套调用里误把该视图当原图。
不能直接拿加入安全边距的遮罩宽高当作未加边距的原始车牌尺寸。

GPU 视频路径 `CUDAFrames.masked` 已为跟踪取得原分辨率 CPU gray；后续方案应优先复用该证据，
避免逐候选重复下载 CUDA 裁剪或增加新的模型来判断是否值得复核。图片和其他调用路径也须覆盖。

## 先用现有素材标定

用户已确认使用现有素材。先查看完整车牌视频和可用固定图片的原始裁剪，记录尺寸、清晰度、
可辨识性标签及相邻帧变化，再选保守规则；目前不设经验像素门槛、Laplacian 门槛或置信度门槛。
锐利边框、保险杠、噪声也可能产生高梯度，单一锐度数值不能直接证明字符可辨识。
诊断中的既有遮罩可用于定位裁剪，但它含 padding 且可能包含人脸，需人工剔除非车牌并标出目标本体。

原始裁剪与精确 PTS、源文件哈希保存在
`data/validation/route-a-plate-readability-calibration-20261025-01/`。
人工放大图只方便检查；判定始终基于原始像素，不能把插值后的字符边缘当成原始细节。

首批已从原视频提取并人工查看 15 个源裁剪，精确 PTS、哈希与初步标签存为 manifest.json/review.json，
没有依赖检测置信度。帧 1010/1080 作为清晰必遮锚点，984/1200 作为不确定/边缘截断而保留处理的锚点；
其他所查画面中的车牌字符明显不可辨识，只作为后续额外工作跳过的候选，不能外推到整片其他目标。
其中也有尺寸逐渐增大但仍严重模糊的状态，不能只靠最小尺寸过滤。

这些裁剪的定位区域包含车身、边框与 padding：不可辨识帧 520 的整体 Laplacian 方差约 2045，
而清晰帧 1010 约 668，说明不能对这种整个候选周边裁剪直接设“低锐度才不可读”的统一阈值。
这不是车牌本体的清晰度真值，也未据此选取生产阈值；后续须定位目标本体，补清晰小牌与临界连续帧，
确保保守边界不能跳过仍可辨识的小牌。两张原尺寸/放大显示对照表已保存，运行代码和服务器版本未改。

## 实现与验收前必须证明

| 场景 | 所需行为与证据 |
| --- | --- |
| 清晰但模型低分 | 仍能触发必要确认并遮挡，不能因低分按模糊过滤 |
| 确实不可辨识的极小车牌 | 额外局部确认、找回与无效全量复查次数减少 |
| 大尺寸严重模糊车牌 | 依原图内容判定；不能因尺寸大就持续放大确认 |
| 极小但尚能辨识、边界不确定 | 保守保留确认，不套统一最小尺寸直接放行 |
| 小变大、糊变清晰 | 后续帧重新进入正常检测/确认，覆盖当前可辨识目标；无永久负缓存 |
| 跟踪失配/陈旧/镜头切换 | 不让旧不可辨识状态延续到新的清晰目标；无无限拖尾 |
| 已确认的正常车牌及人脸 | 保持既定有效遮挡、误遮、闪烁与拖尾要求 |
| 推理异常 | 保持失败关闭，不因可辨识性分支返回未处理原帧 |

先用边界与状态转换回归验证逻辑，再在服务器独立比较模型调用次数、主机/GPU 成本及普通双流双文件
整体结果。记录逐项省掉的工作与额外判定成本；不以少算或短片差异替代质量、整片、实时和 30 分钟验收。
固定对照与旧输出保留，允许的新遮罩差异须逐目标依新标准复核，不能自动删除原必验区域或把差异数当漏遮率。
