# rfm 多车固定素材复现与新鲜车牌模板回退实验

**结论：候选撤回。** 文件吞吐改善伴随已有中等车牌遮挡丢失，不能采用。

## 素材与边界

2026-10-27 用户录制两段当前 rfm（25WY170049-01）原始视频，原片位于：

- `data/recordings/rfm-live-20261027-150312/rfm-original-001.mkv`：91.937 秒，640×480，2208 帧。
- `data/recordings/rfm-live-20261027-150915/rfm-original-001.mkv`：89.738 秒，640×480，2230 帧。

原始 MKV 保留 H.264/G711A，不修改。用于 API 文件诊断的 MP4 保持全部 H.264 包，
音轨转为 AAC；其封装对原始重复时间戳作最多约 3.687/0.750 毫秒的单调调整，
不以它替代原始时间戳异常复现。两个文件的 SHA256、逐包核验和完整解码证据均已保存。

本机 GTX 1080 已按原始时间戳定时送入生产 `process_stream`，实际走 NVDEC、GPU
检测/遮罩、NVENC，输入/输出为本地适配器，未包含网络与浏览器。
本机为 FP32 主车牌模型，不能代替 RTX 的 FP16 性能。双流定位采样在处理约 13/19 秒
素材后主动结束，保留 interrupted 标记，不能写成完整实时回放或持续吞吐通过。
证据 `data/validation/rfm-recorded-replay-20261027-01/`。

现有 `18554` 转发可连接服务器 MediaMTX，但独立测试输入路径发布握手返回 401；
当前 `Publisher.authorize` 仅准许任务 worker 发布 `redacted/{task_id}`。
未关闭鉴权、修改服务器配置或增加远程命令。服务器双路原速回放仍待具备合法测试入口。

## 单变量候选

只在 `FrameRedactor` 的光流路径增加新鲜车牌回退：LK 失败，且车牌距上次实际检测
不超过 0.2 秒时，尝试现有 `_follow` 的正反向模板验证。成功则继续跟踪；失败仍全量复核。
回退不续期检测时间，不延长 0.5 秒轨迹期限，不改变模型、阈值、遮罩边距或输入帧数。
周期全量检测和逐帧新车牌提案扫描保留；新提案仍在当前帧触发既有确认流程。
`template_fallbacks` 单独计数，`flow_failures` 仍统计由回退覆盖的 LK 失败。

该变化可能改变跳过帧上的位置与拖尾，必须检查实际素材中的覆盖、新目标出现和离开。
代码与单测通过不等于质量或性能通过；仅作为可回退实验候选。

## 验证与采用门槛

先写回归用例，原逻辑 2 失败、2 通过；覆盖新鲜匹配成功、匹配失败、陈旧轨迹和新车牌
同帧发现。候选相关跟踪/遮挡/可读性单测 77 通过，实时 CUDA 接线/统计单测 52 通过。
实际 GPU 媒体检查 2 通过（两个 tracking 组合的全部帧、PTS、AAC 完整性）。
`test_flow_proposals_recover_entry_growth_and_profile_expiry` 在候选和单独导出的
`0145815` 基线下都失败于 `face_rechecks > 0`；首个目标遮挡断言此前已执行通过，
其余场景未跑到。保留原断言，不能称整个质量回归通过，也不据此宣称候选引入或修复了问题。
RTX 完整文件对照、持续实时回放及本轮质量审阅结果仍待补充。

只有实际减少昂贵调用、完整媒体保持不变且可确认的车牌/人脸覆盖不退化时才保留。
没有超出波动的整体或长尾收益，或出现新增清晰车牌漏遮时，撤回候选并保留证据。
回退使用新提交或已推送不可变 tag，不覆盖任何实验标签。

遮挡几何证据因 64 KiB 限制截断；对照/候选可比较前 702/937 帧。
几何差异仅用于定位，不能当作漏遮真值。人工查看原片、对照、候选及原分辨率裁剪：

- 第一段第 188 帧减少了地面的拖尾误遮，第 28 帧减少车体边缘误遮。

  违反既定中大目标遮挡不得整体退化的约束。原分辨率字符可读性没有正式标注，
  不将差异数量转换为漏遮率，也不因不确定字符可读性就放宽已有覆盖。
