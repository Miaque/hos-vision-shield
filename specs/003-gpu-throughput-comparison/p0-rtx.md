## RTX B 的定点质量复核

从普通输出按原 PTS 提取原始像素尺度 source/B 证据，位于
`data/validation/route-b-rtx-p0/quality-witnesses/`，包含六张对照及独立人工判定。
人脸视频原第 449 帧确认楼宇背景标牌文字被误遮，原本称“点阵背景”的负例实际框落在标牌上；
之前的最小修复 shadow 仍失败，因此不能宣称 B 已解决误遮。
车牌第 900/1200 帧可定位车牌区域被遮挡，原文字有模糊/边界截断，不据此报告可读车牌召回率。
夜间第 1016/1017 帧仍是左边界截断且运动模糊的入画半脸，1018 开始覆盖，与已审阅的本地
连续片段相符；只在该处沿用两帧入画边缘容忍，不扩展到清晰正脸。
这些是定点证据，没有标注整片统计分母，不报告准确率，也没有通过最终质量验收。

## 首次 CUDA 采样失败及修复

主人脸任务 `f93a73fb-298a-43f8-9c9f-1d2e17fba399` 在累计处理 697 帧后失败，未发布结果。
三个实际前向原始 trace 均保存，但第 768 次的 CUPTI runtime tid 沿用前一执行线程 43458，
CPU 父范围 tid 已为 45048，旧版按线程筛选误判“无关联内核”。
修复按父范围及其同线程 CPU 算子的 External id 关联，带 ID 时不依赖失真的 CUDA tid；
无 ID 的 ORT 调用保持原线程/时间范围。回归先复现误归因，再验证不混入并行模型或父范围外算子。

三份 RTX 原始 trace 离线重算为 2289/2289/2266 个关联内核；GPU busy 分别为
13.760/14.852/14.319 ms，host 范围为 32.359/48.244/34.419 ms。
host 与 busy 的差值还包含分发、同步、空隙及采样影响，不能直接称为排队等待。
该旧报告没有记录准确采样视图，不能把三点假定为同尺寸全图，也不将失败任务计整片或吞吐。
修复标签 `exp-20261023-b-profile-04`（`9399e58`）已部署，54 项检查通过，
补充样本源帧/视图上下文后使用独立 `*-v2/` 目录重跑四个模型；保留全部原失败证据。
