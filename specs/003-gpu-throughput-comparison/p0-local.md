## 四模型真实调用与计时样例

取 `host-codecs-face/report.json`。全部是主机包含时间，含排队/隐式等待；
前十次之后样本仅 2–3 个，不足以声称稳定分位已收敛。

| 模型 | 实际调用数 | host P50 ms | host P95 ms | 首次 ms |
| --- | ---: | ---: | ---: | ---: |
| EgoBlur face | 13 | 129.457 | 225.917 | 344.123 |
| EgoBlur plate | 12 | 117.503 | 123.976 | 126.921 |
| YuNet | 12 | 39.289 | 95.520 | 161.585 |
| HyperLPR detection | 13 | 38.390 | 108.668 | 209.885 |

12 帧不等于每个模型只有 12 次：局部复核确实增加了主脸/补车牌调用。
JSONL 将逐次调用定位到源帧及用途；不再用检测轮数代替 forward 次数。

四组独立设备运行各采第 2/6 次真实调用，所有 trace 重算得到关联 CUDA 内核：

| 模型 | 两次内核数 | GPU 活跃并集 ms | 同步 API 主机时间 ms |
| --- | --- | --- | --- |
| EgoBlur face | 2110 / 2110 | 113.959 / 111.161 | 55.900 / 51.112 |
| EgoBlur plate | 2109 / 2087 | 111.591 / 111.177 | 62.218 / 63.156 |
| YuNet | 150 / 150 | 4.189 / 4.425 | 0.005 / 0.006 |
| HyperLPR | 434 / 434 | 3.107 / 3.788 | 0.036 / 0.038 |

这是两个样本的诊断区间，不是 GPU 稳态 P50/P95，更不是 RTX 成绩。
例如 YuNet 主机前向 21.288/37.732 ms，而关联内核与复制活跃并集只有 4.189/4.425 ms；
不能把全部 host 时间归为卷积计算，也不能仅用传输字节少推定没有等待。
EgoBlur trace 存在多个内部 CUDA stream，内核耗时之和与活跃并集不同，不直接相加。

Kineto 在部分工作线程采样时打印 `External init callback must run in same thread as registerClient`；
进程返回 0，八份 trace 均含关联内核且输出不变。保留此现象，服务器采样仍需独立复核。

## B 原始人脸视频完整诊断

已完成原始 `人脸视频1.mp4` 全部 **2450 帧**：零丢帧，所有有理数 PTS 与 1920×536 尺寸保持；
源本来无音频。实际 NVDEC/NVENC，输出 SHA256
`bf53e5aff39b025ce6ae044500935129a0e72a1014dcc822be7b360609c46ffe`。
这仍是 GTX 1080 单路 host 诊断，媒体 3.22328554 FPS，不是 RTX 6000、双路、普通吞吐或质量验收。

| 模型 | 真实 forward | 次/帧 | host 累计秒 | host P50/P95 ms |
| --- | ---: | ---: | ---: | --- |
| EgoBlur face | 3892 | 1.589 | 419.106 | 128.734 / 136.141 |
| EgoBlur plate | 2499 | 1.020 | 303.282 | 122.898 / 127.183 |
| YuNet | 3166 | 1.292 | 96.621 | 35.286 / 41.708 |
| HyperLPR detection | 2742 | 1.119 | 90.643 | 35.143 / 40.690 |

主脸的 3892 次包括：2450 次整帧、616 次初检候选局部确认、30 次局部放大恢复、
540 次跟踪框复核，以及跟踪复核内部另触发的 248 次局部确认与 8 次放大。
相比帧数多 **1442 次**，额外主脸 forward 累计约 96.134 秒；这些用途有互补质量意义，
**不能直接删除**，下一步需要实际输入/目标证据判断能否减少重复计算。

其他累计包含时间：检测 742.071 秒，局部确认 68.528 秒，跟踪复核 57.585 秒，
显式同步 7.488 秒，灰度复制 2.615 秒，颜色转换 2.455 秒，编码及收尾 1.468 秒，GPU 遮罩 0.724 秒。
嵌套/并行不能相加；同步也不能简单视为可直接消除的开销。
本机证据首先指向主模型调用成本，不能靠重复接入已有的 NVENC 声称解决吞吐目标。
没有将本机的成本比例直接外推到 Ada。

同一原视频 80 秒处另取 12 帧做**非空 GPU 遮罩**检查：host 与未包装处理逐字节一致、
所有帧时钟/尺寸一致，画面实际出现人脸深灰遮罩；SHA256
`fac9c9e6ec71bbcbdebc844188b7e058fa46834fd8592f9ef5fe5bde8b89898d`。
这证明工具未改变该短片输出，不代表完整视频所有目标的质量已通过。

完整记录：`full-face-host/report.json`、`full-face-host/calls.jsonl`、

## 诊断工具计时口径补正
