# Ada 主车牌骨干融合实验（2026-10-25）

本实验以内部异步迁移与 attempt 诊断、停流顺序修复为基础，保持两路流、两个 GPU 文件并发。
已撤回无稳定整体收益的单图 ROI 格式改写；原 ROI 格式、RPN、候选数量、NMS、四层 ROIAlign
与后续检测规则均保留。固定算法对照 `581c175a` 不变，本项的直接执行对照为
`0bcddc7` / `exp-20261025-a-single-image-pooler-control-01` 的运行代码。

## 新的验证条件与实现

历史骨干冻结只在 GTX 1080 上测试，完整前向仅改善约 0.37%，未采用。
当前 RTX 6000 Ada trace 中仍有 112 个 BatchNorm，卷积与小算子发射的成本比例已不同，
本轮以减少 Ada 上归一化执行及发射成本为新假设，不原样宣称旧实验已有收益。

只冻结主车牌骨干，然后将其内联进复制的原包装图。原模型图不被修改；保持 FP32 归一化缓冲区、
原半精度执行契约及 CPU 尺寸元数据，并沿用 17 个内部设备迁移的异步标志。
包装层结构不符、归一化未折叠或设备迁移节点不符时失败关闭，不静默切换执行路径。

[PyTorch freeze 说明](https://docs.pytorch.org/docs/2.9/generated/torch.jit.freeze.html)明确指出，
数值优化并不保证逐位一致。权重文件与精度配置虽未改变，融合仍会折叠参数并改变运算顺序，
因此必须独立校准半精度框、分数、最终遮罩及媒体输出，不能只检查算子数量减少。
