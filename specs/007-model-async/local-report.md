独立固定真实像素各采3次CUDA trace，与整片吞吐运行分开：

同步API区间和GPU busy会重叠，不能相加或全部视为可删除等待。primary每次33个同步API事件，HtoD约27–35KB、DtoH仅57 bytes；不能把这些小额搬运当成整张图重复上传。采样器会增加开销，固定320视图是缩放整图而非真实复核ROI，且没有并行其他模型；该表只作设备路径证据。

特别注意：服务器Ada已有 `_HalfPlate` 与17个内部异步device move图改写，GTX970走另一分支；**不能把本机33次同步的修法重复建议给服务器**。detail host与GPU区间的差值也尚未拆成确切CPU/ORT/调度成分，不强行归因。

另对8个固定rfm真实解码画面，模型预热后只改变quality的primary调度（原线程池/同线程串行，detail内部池不变），交替3轮，所有检测输出完全相同：

## 4. 可支持的最小候选

1. **E1已经有独立媒体调度收益证据**：只取消明显迟到的due重设，保留实际释放半帧下限、.5s限幅、PTS、音频、前视和停止。独立commit `d6f24d0ac4679b1ea09bbc0a5efe0fe2fec99d10`，不合入本诊断。两轮固定ROI+相同注入成本的真实音视频/RTSP测试5.983/5.989→5.345/5.351秒，耗时减少10.67%/10.66%。它不是rfm实际模型收益。
2. **模型行为优化尚无已证明的赢家**。输入像素已有共享、face/detail已有并行和缓存；primary/detail最终张量契约不同。重复prepare/同步值得核算，但本地主线程显式同步合计仅1.23ms/帧，远小于primary plate关键路径，且其中包含必要的生产者/消费者同步。
3. cached proposal路径提前启动primary plate会在质量门控不触发全图时增加推测工作；不作为“只改调度且无额外成本”的方案。先用RTX关联结果核对全图/局部车牌forward、输入准备及实际竞争，再提出单变量候选。没有降低检测频率、阈值、取消复核、扩大队列或隐藏丢帧。

E1本地unit915 passed/96 skipped、最终相关122 passed；真实媒体6 passed，含GTX970真实NVDEC/CUDA/NVENC。真实GPU场景只证明正确性，收益来自固定ROI/注入成本夹具；真实rfm模型E1、RTX文件、长期积压和播放器尚未通过。独立工作树报告 `C:/Users/zhanjh/.codex/worktrees/stream-e1-no-rebase/vision-shield/specs/007-async-critical-path/e1/local-validation.md`。

## 5. 观测开销、测试与限制

- 单轮全片普通/async-host总墙钟差1.50%，媒体处理墙钟差1.26%；不能当作精确稳定开销，也不能把统计噪声解释为优化收益。
- CPU夹具每帧24个嵌套stage和1个future，交替3轮，新关联观测增量CPU中位 **.781ms/夹具帧**，wall约.850ms/帧。内存另跑，retained约1.54MB、peak约1.56MB，基准host观测约1.12MB。tracemalloc不参与上述时间判断。它不包含GPU/Redis/HTTP及E0 StreamProbe。
- `process_video`没有E0 StreamProbe，故本次**没有测到E0实际开/关增量**。此前E0实机report约2.8ms/帧也不能全部算成E0新增开销；这一项仍需受控实机对照，不能用文件路径的无效开关冒充。
- 本候选完整unit **926 passed、96 skipped、9 warnings**。两次中断产生的旧unit日志不作最终结果。之后仅增加report字节预算耗尽时的拒绝成功逻辑（防Future callback吞异常导致残缺报告），相关 **7 passed**；成功媒体路径和模型调用未再改。实测源指纹和这项后续差异均保留，未把旧hash改写成新hash。
- 每请求任务上限25000、事件64MiB、已有测量250000；超限失败，普通请求不安装钩子，不新增逐帧CUDA同步。真实完成事件最大221189 bytes，小于256KiB子进程协议限制。
- Windows `perf_counter`用于新事件，实际声明分辨率100ns；thread CPU来自GetThreadTimes，单次短调用仍有量化误差，只作聚合辅助；不按wall减CPU推算GPU。不同观测时钟域不直接相减。
- 最初verbose试跑 `async-full-a`主动中止，且与E1 GPU测试重叠，未用于吞吐/完整性结果；保留hash不伪装完整样本。
