# CPU / GTX 1080 固定测试集对比

日期：2026-10-19。全部运行完成。

本文保留 GPU 两路检测串行执行时的 CPU/GPU 基线；后续调度优化的最新结果见 [GPU 同效果优化记录](gpu-performance.md)。

## 范围与方法

- 使用既有测试集全部16张原始JPEG，以及事先固定的5段约1秒视频片段，完整逐帧处理104帧；不是五段原视频全长。
- 同机Intel i5-10400、GTX 1080 8GB、驱动582.78，PyTorch 2.14.1+cu126 / torchvision 0.29.1+cu126。
- 两种模式均使用quality四模型、最长边1280、扩框0.15、Torch4线程、OpenCV2线程、并发1；仅EgoBlur设备不同。
- 复用生产图片和视频处理器；每种设备分别运行图片和视频批次，批次内模型驻留，CPU/GPU没有并行推理。
- 处理计时包括解码、检测、遮挡和编码，不含API、队列、网络、进程启动、输出核对或每任务模型重载。初始化包含权重校验，另计。每份素材为单次测量，不是多轮均值。
- 21份原始素材、5份选定片段及4个模型校验通过，源码指纹保留于JSON。没有改模型或算法参数。

## 汇总

| 范围 | CPU处理秒 | GPU处理秒 | 加速比 |
| --- | ---: | ---: | ---: |
| 16张图片 | 109.74 | 20.82 | 5.27倍 |
| 5段片段 / 104帧 | 878.14 | 125.96 | 6.97倍 |

视频加权处理吞吐：CPU 0.118 fps，GPU 0.826 fps，GPU仍未达到源视频实时处理要求。

| 批次 | CPU初始化秒 | GPU初始化秒 |
| --- | ---: | ---: |
| 图片 | 2.866 | 3.170 |
| 视频 | 2.802 | 3.065 |

## 效果与完整性

- 16份JPEG和5份MP4全部逐字节一致（21/21）。21个素材的编码前遮挡RGB与最终解码画面均一致。
- 104帧的视频帧数、尺寸与源时间戳检查通过，文件处理未抽帧。
- 已有标注区域在CPU/GPU下共42次核对，全部通过。标注仅覆盖部分目标及已知误遮区域，不是全量人工标注。
- 历史 `rtsp-green.png` 仍缺失，不把对应历史质量集合或真实RTSP计入本次通过范围。
